# Journal version

- `research/`: journal scouting and comparable papers.
- `analysis/`: pre-registration, analyses A–D and their outputs.
- `figures/`: figure scripts and outputs.
- `manuscript/`: journal manuscript.
- `replication/`: README, licence and citation file of the Zenodo package, and `build_zenodo.sh`, which builds it into `_local/zenodo/` from a commit.
- `CHANGES_vs_coursework.md`: every change to code or analysis relative to `main`.

Paths: scripts read code and data from this repository root. In this worktree the coursework data live in the main checkout, so run scripts with `SHR_MAIN_ROOT=~/Proyectos/spain-holiday-roots`.
